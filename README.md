# おひとりONU

カードゲーム **ONU** のルールブックを、そのまま一人用にしたブラウザゲームです。
あなた＋CPU3人の4人卓。合計点が一番低い人が勝ちます。

**遊ぶ:** `index.html` をブラウザで開くだけ。ビルド不要、依存パッケージなし、1ファイル完結です。

## モード

| モード | 内容 |
|---|---|
| チュートリアル（6ラウンド） | 開始時に **「UNO で遊んだことがあるか」** を聞き、答えで説明の細かさを変えます。実際に遊びながら、画面下の案内が**一手ずつ**「いま何を押せばいいか」を教えます。配り札とCPUの手は台本で固定してあり、その回に覚えることが必ず起きます。押すべきカード・ボタンは持ち上がって光り、矢印が指します。自分の番は操作すれば次へ進み、相手の番の説明は卓を止めて「次へ」で再開します。 |
| ふつうに遊ぶ | 5 / 7 / 9 ラウンド。正規の7枚配りで、CPUも割り込み・オヌスペを狙ってきます。 |

### チュートリアルの2つの道すじ

同じ6ラウンドの台本（配り札とCPUの手）を使いますが、説明の文面は別々に用意してあります（`STEPS_INTRO` / `STEPS_UNO`）。

**「UNO なら知っている」** — 冒頭で *UNO と同じところ* と *ONU で決定的に違う3つ* を提示してから始めます。

1. **点の付き方が逆** — 上がった人が −20点、上がれない人は手札に残った点が失点。ONU の目的そのもの。
2. **重ねだしと、上がり札の制限** — 同じ数字は何枚でも同時に。ただし上がりに記号カードは使えない。
3. **ドローの押しつけ返し** — 重ね返しが正式ルール。アウトオブプレイ。ワイルドが20点で重い理由。
4. **オヌ宣言** — UNO の「ウノ！」にあたる。受付はインプレイの間だけで、宣言状態が特殊上がりの前提になる。
5. **割り込み** — 色も数字も同じ札は、自分の番でなくても出せる。
6. **オヌスペと集計** — 点数計算がそのまま必殺技。返し・破りの存在と、最終順位。

**「はじめて（UNO も知らない）」** — 同じ台本を、用語を出す前に必ず説明する文面で進めます。第1ラウンドは
矢印で **手札 → 場 → 山 → 対戦相手** の順に画面を案内してから、「色か数字が合えば出せる」の一行に入ります。

## 実装しているルール

- 場のカードと同じ色・同じ数字・同じ文字なら出せる
- **重ねだし**（同じ数字／同じ文字を何枚でも同時に）
- **割り込み**（色も数字も同じ札は順番に関係なく出せる）
- Reverse は奇数枚で逆回り・偶数枚でそのまま／Skip は 2×枚数 人先へ
- Draw2・Wild Draw4 の重ね返し（返せなかった人が 枚数×2／枚数×4 枚）と**アウトオブプレイ**
- 山切れ時は捨て札を切り直して山に戻す
- **上がりの札に文字カードは使えない**

### 上がり方と得点

| 役 | 得点 |
|---|---|
| オヌ上がり | −20 |
| オヌスペ | −20 |
| 重ね上がり | 0 |
| 割り込み上がり | 0 |
| オヌスペ返し／破り | 返した人 −50、返された人 +50。連続すると倍々（+50 → +100 → +200 …、最後に上がった人は −50×2の(回数−1)乗） |
| 16枚返し | 一度に16枚引いた人がそのラウンドで上がると、その人 −40、他の人は手札合計の2倍 |

上がれなかった人は、手札に残ったカードの点数がそのまま加算されます（数字はその数字、Skip・Reverse・Draw2 は10点、Wild・Wild Draw4 は20点）。

## 一人用にあたって決めたこと

- 本来は早い者勝ちのリアルタイム勝負なので、**カードが場に出るたびに走る3秒の「インプレイ」**に置き換えています。割り込み・オヌスペ・オヌ宣言はこの間だけ受け付けます（チュートリアルでは4.6秒）。
- オヌの言い忘れは、インプレイ中に指摘されれば4枚、指摘されずに順番が戻ってくれば1枚。CPUの言い忘れはこちらから指摘できます。
- CPUはオヌスペを常に見抜くわけではありません（見逃し率あり）。先に気づけば自分のものにできます。
- Wild Draw4 の重ね返しは（枚数×4）枚引きとして実装しています。ルールブック本文は「×2」ですが、特殊ルール「16枚返し」が Wild Draw4×4枚＝16枚を前提にしているため、そちらに合わせました。
- チュートリアルは各ラウンドを短く区切るため、練習用に手札を2〜5枚に減らしています。

## 技術メモ

- 依存なしの単一 HTML。フォントのみ Google Fonts（Dela Gothic One / Zen Kaku Gothic New / Archivo Black / Roboto Mono）。
- **効果音は Web Audio API で合成**（音源ファイルなし）。カード系は正弦波のピコ音ではなく、帯域を絞った短いノイズ（紙の擦れ）と低域の当たり音を重ねて作っています。配る／めくる／場に置く／山を切る／札を選ぶ／Skip・Reverse の風切り／オヌ宣言のチャイム／ラウンド終了など。ヘッダーの「🔊 音」でオン・オフでき、設定は localStorage に残ります。ブラウザの自動再生規制に合わせ、最初の操作で音を解禁します。
- カードの移動・めくりは Web Animations API。`prefers-reduced-motion` を尊重します。
- チュートリアルの山札は決定論的シャッフル（シード固定）なので、何度やっても同じ場面が出ます。
