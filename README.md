# おひとりONU

カードゲーム **ONU** のルールブックを、そのまま一人用にしたブラウザゲームです。
あなた＋CPU3人の4人卓。合計点が一番低い人が勝ちます。

**遊ぶ:** `index.html` をブラウザで開くだけ。ビルド不要、依存パッケージなし、1ファイル完結です。

## モード

| モード | 内容 |
|---|---|
| チュートリアル（6ラウンド） | 開始時に **「UNO で遊んだことがあるか」** を聞き、答えで説明の細かさを変えます。実際に遊びながら、画面下の案内が**一手ずつ**「いま何を押せばいいか」を教えます。配り札とCPUの手は台本で固定してあり、その回に覚えることが必ず起きます。押すべきカード・ボタンは持ち上がって光り、矢印が指します。自分の番は操作すれば次へ進み、相手の番の説明は卓を止めて「次へ」で再開します。 |
| ふつうに遊ぶ | 5 / 7 / 9 ラウンド。正規の7枚配りで、CPUも割り込み・オヌスペを狙ってきます。 |

ヘッダーの **「🏠 最初へ」** でいつでも最初の画面に戻れます（進行中なら確認が入ります）。

### チュートリアルの作り

ゲーム開発のチュートリアル設計でよく挙がる原則に沿っています。

- **一度に1つだけ教える** … 冒頭で全ルールを並べず、必要になった場面でその都度。
- **区切る場所を選ぶ** … 文の数で機械的に切らず、**図が切り替わるところ**と**話の転換点**でだけ区切ります。
  1メッセージは2〜3行（40〜100字程度）。卓と手札のあいだに置いた**独立のメッセージ枠**に出ます。
  肩の見出しが赤の「せつめい」なら読むところ、金の「あなたの番」なら操作するところ。
  文字送りが終わると右下に **▼** が点滅します。ボタンは置いていません（あると「そこを押さないと
  駄目」に見えるため）。代わりに最初の3回だけ、▼のすぐ左に **「この枠内のどこを押しても次へ進めます」** を
  枠なしの光る文字でふわっと出し、以降は消えます。
- **見せる** … 文を送るたびに卓の上へ図が出ます。カードを金色の枠で囲む／札に「出せる」「出せない」「7点」などの札を貼る／場の札と手札を線で結んで「4 = 4」と示す／得点を数字で浮かせる。
- **やらせる** … 説明のあとは必ず操作させます。押すべきカード・ボタンは持ち上がって光り、矢印が指します。操作すれば次へ進むので「次へ」ボタンは出ません。
- **待たせない／急かさない** … 相手の番など操作しない場面では卓を止め、「次へ」で再開します。

開始時に **「UNO で遊んだことがあるか」** を聞き、2つの文面を出し分けます（`STEPS_INTRO` / `STEPS_UNO`）。
台本（配り札とCPUの手）は共通で、その回に覚えることが必ず起きるように固定してあります。

| ラウンド | 覚えること |
|---|---|
| 1 | **点の付き方**。上がった人が−20点、上がれない人は手札に残った点が失点。ONU の目的そのもの |
| 2 | 順番を動かす札（Skip・Reverse）と、同じ数字をまとめて出す**重ねだし**。上がり札の制限 |
| 3 | **ドロー2の押しつけ返し**とアウトオブプレイ。ワイルドが20点で重いこと |
| 4 | 残り1枚の**「オヌ！」宣言**と、受付時間（インプレイ） |
| 5 | 順番を無視して出せる**割り込み** |
| 6 | 手札の合計と場の点数が一致したら全部出せる**オヌスペ**、そして最終集計 |

「はじめて」を選ぶと、第1ラウンドの冒頭で矢印が **手札 → 場 → 山 → 対戦相手** と画面を案内し、
「色か数字が合えば出せる」を手札3枚それぞれに札を貼って確かめてから、実際に出させます。

## 実装しているルール

- 場のカードと同じ色・同じ数字・同じ文字なら出せる
- **重ねだし**（同じ数字／同じ文字を何枚でも同時に）。札は**選んだ順に場へ置かれ、最後に選んだ札が場のカードになります**。先頭は場に合う札である必要があるため、合う札を選ばないと出せません
- **割り込み**（色も数字も同じ札は順番に関係なく出せる）
- Reverse は奇数枚で逆回り・偶数枚でそのまま／Skip は 2×枚数 人先へ
- Draw2・Wild Draw4 の重ね返し（返せなかった人が 枚数×2／枚数×4 枚）と**アウトオブプレイ**
- 山切れ時は捨て札を切り直して山に戻す
- **上がりの札に文字カードは使えない**

### 上がり方と得点

| 役 | 得点 |
|---|---|
| オヌ上がり | −20 |
| オヌスペ | −20 |
| 重ね上がり | 0 |
| 割り込み上がり | 0 |
| オヌスペ返し／破り | 返した人 −50、返された人 +50。連続すると倍々（+50 → +100 → +200 …、最後に上がった人は −50×2の(回数−1)乗） |
| 16枚返し | 一度に16枚引いた人がそのラウンドで上がると、その人 −40、他の人は手札合計の2倍 |

上がれなかった人は、手札に残ったカードの点数がそのまま加算されます（数字はその数字、Skip・Reverse・Draw2 は10点、Wild・Wild Draw4 は20点）。

## 一人用にあたって決めたこと

- 本来は早い者勝ちのリアルタイム勝負なので、**カードが場に出るたびに走る3秒の受付時間**に置き換えています（ルールブックでいう「インプレイ」）。割り込み・オヌスペ・オヌ宣言はこの間だけ受け付けます（チュートリアルでは4.6秒）。
  画面上の表記は「わりこみ受付」「引いています」といった日本語にしてあります。
  チュートリアルでは、こちらに宣言も割り込みもできない受付時間は0.4秒に詰めて待たせません（実測：全36回のうち28回が短縮）。
- オヌの言い忘れは、インプレイ中に指摘されれば4枚、指摘されずに順番が戻ってくれば1枚。CPUの言い忘れはこちらから指摘できます。
- CPUはオヌスペを常に見抜くわけではありません（見逃し率あり）。先に気づけば自分のものにできます。
- Wild Draw4 の重ね返しは（枚数×4）枚引きとして実装しています。ルールブック本文は「×2」ですが、特殊ルール「16枚返し」が Wild Draw4×4枚＝16枚を前提にしているため、そちらに合わせました。
- チュートリアルは各ラウンドを短く区切るため、練習用に手札を2〜5枚に減らしています。
- 重ねだしの並び順は「選んだ順」＝場に置く順です。たとえば場が赤3で赤7と青7を持っているとき、赤7→青7 の順に選べば場は青7になります。異なる色をまたぐときは、手札の下に**どの札が場になるか**を表示します。

## 技術メモ

- 依存なしの単一 HTML。フォントのみ Google Fonts（Dela Gothic One / Zen Kaku Gothic New / Archivo Black / Roboto Mono）。
- **効果音は Web Audio API で合成**（音源ファイルなし）。カード系は正弦波のピコ音ではなく、帯域を絞った短いノイズ（紙の擦れ）と低域の当たり音を重ねて作っています。配る／めくる／場に置く／山を切る／札を選ぶ／Skip・Reverse の風切り／オヌ宣言のチャイム／ラウンド終了など。ヘッダーの「🔊 音」でオン・オフでき、設定は localStorage に残ります。ブラウザの自動再生規制に合わせ、最初の操作で音を解禁します。
- カードの移動・めくりは Web Animations API。`prefers-reduced-motion` を尊重します。
- チュートリアルの山札は決定論的シャッフル（シード固定）なので、何度やっても同じ場面が出ます。
- **画面はスクロールさせない設計**。卓・メッセージ枠・手札が常に1画面に収まるよう、
  高さは `100dvh` 基準で卓が伸縮します。狭い端末（幅760px以下）と縦の短い窓（高さ720px以下）に
  別々の調整を入れてあり、360×520 まで縦横ともスクロールなしを確認しています。
- チュートリアル中は卓のログを隠します（読むものが増えて画面が狭くなるため）。ふつうに遊ぶモードでは出ます。
